# How to play

One page per game: what you're doing, how a round goes, what the settings change, and what happens when someone's phone dies mid-round. Same sections as the host's game list.

New here? Start with [Rooms and the lobby](rooms.md): making a room, getting friends in, and what the host can do.

## Cards

| Game | Players | |
| --- | --- | --- |
| [Sevens](sevens.md) | 2–16 | Build each suit out from the seven. |
| [Crazy Eights](crazy-eights.md) | 2–10 | Match suit or rank; eights are wild. |
| [Old Maid](old-maid.md) | 2–10 | Pair off, draw blind, don't get stuck with the odd one. |
| [Go Fish](go-fish.md) | 2–6 | Ask for ranks, collect books of four. |
| [President](president.md) | 3–8 | Shed your hand; finishing order sets next round's pecking order. |
| [Cheat](cheat.md) | 3–10 | Play face down, claim anything, call out liars. |
| [Oh Hell](oh-hell.md) | 3–7 | Bid exactly how many tricks you'll take. Hand sizes change every round. |
| [Hold'em](holdem.md) | 2–9 | No-limit Texas Hold'em with play chips; blinds climb until someone has everything. |
