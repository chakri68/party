# Fake Word and Bluff Definitions Implementation Plan

**Spec:** `docs/superpowers/specs/2026-10-27-bluff-design.md`. **Template:** `games/imposter`.

Commit straight to master after each task. Targeted check: `pnpm vitest run games/bluff packages && pnpm typecheck`.

### Task 1: Package, types, rules, content

Files: `games/bluff/{package.json,tsconfig.json}`, `shared/{index,manifest,types,rules,rules-text}.ts`, `server/words.ts`, `test/rules.test.ts`, `test/guard.test.ts`.

Tests:
- `words: 60+, none twice, all in the dictionary, a–z 3–18`
- `words: meanings 15–180, in display form, never naming the word, with notes`
- `fakeWordShape: 3–18 letters a–z, lowercased`
- `displayDefinition: lowercase first letter, no trailing period`
- `nearSame: exact, retyped, one word changed; different bluffs pass`
- `settings fields: rounds`
- `guard: client/ and shared/ never import server/words`

### Task 2: Server

Files: `server/{index,game}.ts`, `test/game.test.ts`.

Tests (both variants where it matters):
- `createGame: write phase, prompt public, answer secret, 3–12`
- `secrets: answer and authorship absent from public, private and events before reveal`
- `options: opaque ids, shuffled, real one's slot varies by seed`
- `fake word: rejects dictionary words, the real word, near misses, duplicates, bad shapes`
- `definitions: rejects short, near the real one, near another`
- `write: once each, early close when everyone's in, timer closes, no fakes skips the vote`
- `deadline: actions at the deadline are rejected before the alarm; early alarm re-arms`
- `vote: not your own, re-vote overwrites, early close`
- `scoring: +2 real, +1 per fooled opponent`
- `rounds: next by host or timer, no repeated words, finishes with shared winners, carryOver`
- `leaving: entry stays, dropVoter, below 3 abandons; away players don't hold a phase`
- `skip: host skip in write and vote`
- `random games: always finish`

### Task 3: Client and registration

Files: `client/{index,view}.ts`, `client/styles.css`, `client/env.d.ts`, `apps/server/src/games.ts`, `apps/web/src/games.ts`, both apps' `package.json`.

Check: `pnpm typecheck`, `pnpm build`, and the web build carries no real meaning from the list.

### Task 4: Verify

`pnpm vitest run --testTimeout=60000`, then the report at `.superpowers/sdd/games/bluff-report.md`.
