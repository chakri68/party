# Imposter Implementation Plan

**Spec:** `docs/superpowers/specs/2026-10-27-imposter-design.md`. **Template:** `games/scribbl`.

Commit straight to master after each task. Targeted check: `pnpm vitest run games/imposter games/scribbl packages && pnpm typecheck`.

### Task 1: normalizeGuess moves to @games/words

Files: `packages/words/src/index.ts`, `packages/words/test/text.test.ts`, `games/scribbl/shared/rules.ts`, `games/scribbl/test/rules.test.ts`.

Verbatim move; Scribbl re-exports it from its rules. The test moves with it.

### Task 2: Package, types, rules, content

Files: `games/imposter/{package.json,tsconfig.json}`, `shared/{index,manifest,types,rules,rules-text}.ts`, `server/words.ts`, `test/rules.test.ts`.

Tests (`test/rules.test.ts`):
- `pack: 150+ words, 12+ per category, none twice, none naming its category`
- `clueProblem: empty, the word, or containing it`
- `guessMatches: case, spaces, accents, plurals; not one letter off`
- `settings fields: rounds and discussion length`

### Task 3: Server

Files: `server/{index,game}.ts`, `test/game.test.ts`.

Tests (`test/game.test.ts`):
- `createGame: one imposter, everyone else has the word`
- `secrets: public state and the Imposter's private state never carry the word`
- `reveal: acks advance early, the timer acks the rest`
- `clues: one each, 40 chars, the word rejected for innocents only, hidden until all in`
- `deadline: actions after the deadline are rejected before the alarm fires`
- `discuss: host can end it, nobody else`
- `vote: no self-vote, majority accuses, all voted closes early`
- `vote: tie runs a runoff between the leaders; a second tie is settled by hash`
- `vote: nobody voted, Imposter scores`
- `guess: right guess steals, wrong guess pays innocents`
- `rounds: imposter rotates by fewest turns; last round finishes with shared winners`
- `leaving: Imposter leaving drops the round without a score; innocent leaving drops their vote; below 3 ends with no winner`
- `skip: host skip acts for the awaited`
- `random games: always finish`

### Task 4: Client and registration

Files: `client/{index,view}.ts`, `client/styles.css`, `client/env.d.ts`, `apps/server/src/games.ts`, `apps/web/src/games.ts`, both apps' `package.json`.

Check: `pnpm typecheck`, `pnpm build`.

### Task 5: Verify

`pnpm vitest run --testTimeout=60000`, then the report at `.superpowers/sdd/games/imposter-report.md`.
