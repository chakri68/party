# Face-Off Implementation Plan

**Spec:** `docs/superpowers/specs/2026-10-27-face-off-design.md`. **Templates:** `games/dont-say-it` (phases, deadlines), `games/imposter` (ballots).

Commit straight to master after each task. Targeted check: `pnpm vitest run games/face-off packages && pnpm typecheck`.

### Task 1: Package, types, rules, categories

Files: `games/face-off/{package.json,tsconfig.json}`, `shared/{index,manifest,types,rules-text,categories}.ts`, `test/rules.test.ts`. Both apps' `package.json` gain the dependency; `pnpm install`. No registry edits yet (a dev server is running).

Tests:
- `categories: 120+, no duplicates, lowercase, short`
- `settings fields: first to 10 / 15 / 20`

### Task 2: Server

Files: `server/{index,game}.ts`, `test/game.test.ts`.

Tests:
- `createGame: 3–12, everyone holds a different card, a lull with a spark due in 4–9 s`
- `spark: two connected players, never the exact last pair when another exists`
- `duel: first buzz claims; second is too late; time-up after the deadline`
- `no buzz in 8 s: no score, both draw`
- `confirm: voters only, overturn needs more overturns, ties and silence stand, early close`
- `redo: once per duel, same pair re-sparked`
- `secrets: the vote isn't public before the duel resolves`
- `leaving: duelist voids; voter dropped; under 3 ends it`
- `cap: ends in a lull at once, after the live duel otherwise; ties share`
- `random games: always finish`

### Task 3: Client and registration

Files: `client/{index,view}.ts`, `client/styles.css`, `client/env.d.ts`, then `apps/server/src/games.ts`, `apps/web/src/games.ts`, last.

Check: `pnpm typecheck`, `pnpm build`.

### Task 4: Verify

`pnpm vitest run --testTimeout=60000`, then the report at `.superpowers/sdd/games/face-off-report.md`.
